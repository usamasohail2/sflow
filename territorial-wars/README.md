# Islamabad Territorial Wars

A strategy game set across Islamabad's sectors — claim territory, hold ground, outplay rivals.

**Separate** from Islamabad Explore (the community map).

## Dev

```bash
cd territorial-wars
npm install
npm run dev
```

## Routes

- `/` — landing
- `/play` — sector board prototype

## Deploy

Own Vercel project (not `explore-islamabad`).
