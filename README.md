# Signature Flow

Turn your signature into an impressive animation in seconds — start by uploading your SVG or tracing a photo.

## Quick start

1. Open `index.html` in a browser or run a local server.
2. Upload an SVG of your signature, or use "or trace a photo (beta)" to trace from an image.
3. Adjust animation, stroke, and path options, then export (SVG, MP4, or GIF).

## Project structure

- `index.html` – Main app
- `app.js` – Logic, animation, photo trace, export
- `styles.css` – Styles
- `logo.svg` – Logo asset
