Updates and improvements to Signature Flow. We add fixes and features regularly—check back for the latest.

Recent updates

  • Release
    Build ready version (v1.0)

    This build is ready for production. All recent improvements, fixes, and UI updates are included. Signature Flow is ready to ship.

  • Improvement
    Empty state and How it works

    The empty state now shows the full intro line with See how it works. on the next line (clickable). The separate “How it works” button was removed. Clicking “See how it works” only opens the guide modal and no longer triggers the upload dialog. The How it works modal subtitle was removed, and list styling was updated: tighter line spacing with more space between list items for easier reading.

  • Update
    Footer

    The footer background is now transparent so it blends with the page instead of a solid bar.

  • New
    Changelog page

    You can now see what’s new at a glance. A Changelog link was added in the footer (bottom left of the app). This page lists past updates so you can track new features and bug fixes over time.

  • Fix
    Mobile layout fix

    On phones and small screens, the particle background was covering the main content. The particles layer is now behind the UI (z-index adjusted), so the header, preview area, and controls stay visible and usable instead of being hidden behind the effect.

  • Fix
    Trace a photo on mobile

    The “Or trace a photo (beta)” option was getting cut off on mobile. We removed the negative margin that caused clipping and added a subtle text shadow so the label stays readable on both dark and light backgrounds.

  • Fix
    Logo click after photo upload

    If you uploaded a photo for tracing and then clicked the logo to go back, the app didn’t fully reset—SVG upload could stay disabled. Clicking the logo now properly clears the photo-trace state so you can upload a new SVG or start over without refreshing.

  • Fix
    Analyzing photo box removed

    While your photo was being analyzed, a dark box appeared behind the “Analyzing photo…” message. We fixed this by not showing the preview skeleton during analysis and hiding the empty-state content during loading, so the overlay stays clean and minimal.

  • Improvement
    Loading overlay

    Loading states (e.g. “Analyzing photo…”) now use only text on a transparent overlay—no box, spinner, or heavy UI. This keeps the focus on your content and reduces visual noise while something is processing.

  • Feature
    Fullscreen

    The fullscreen button now fullscreens only the animation preview panel. The header and controls are hidden in fullscreen so you get a clean, distraction-free view of your signature animation—ideal for presentations or quick previews.

  • Polish
    UI polish

    Path/flow items now use a neutral grey only, with strokes removed from arrow boxes for a cleaner look. Primary grey was updated across the app for consistency. The showcase video has 12px rounded corners and a light drop shadow in light mode for better depth and alignment with the rest of the UI.

  • Update
    Footer

    The footer contact link was updated to “Say hello!” with a mailto link so you can reach out directly from the app. We’re happy to hear feedback and suggestions.
